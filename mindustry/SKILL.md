# Mindustry: как играть агенту

Всё ниже проверено на практике (steam build 160.7, русский интерфейс), кроме пунктов с пометкой «не проверено».
Состояние кампании и журнал — в `campaign.md` рядом.

## Запуск и доступ

- Игра: `D:\SteamLibrary\steamapps\common\Mindustry\Mindustry.exe` (Steam app 1127400). В меню «Пуск» её нет.
- Запуск: `Start-Process "steam://rungameid/1127400"`.
- `request_access` по имени «Mindustry» НЕ работает — передавай полный путь к exe. Уровень доступа — full.

## Главная грабля: фокус окна

- Когда пользователь пишет в окне Claude, фокус уходит из игры. В фоне игра почти не перерисовывается — скриншоты показывают СТАРЫЙ кадр.
- Если пользователь печатает, пока активна игра, буквы становятся горячими клавишами (русская раскладка = те же физические клавиши): C прячет интерфейс, Пробел — пауза, J — дерево технологий, N — карта планеты, E — выключает строительство, T — окно схем.
- Перед каждой пачкой действий: клик по заголовку окна (≈ 700,10), пауза 0.5–1 с, свежий скриншот. Если `key` падает с «Claude's own window still has keyboard focus» — снова клик по заголовку.
- После каждого сообщения пользователя проверь: виден ли интерфейс (нет → C), нет ли «Пауза» сверху (если не нужна → Пробел), нет ли внизу «[E] для включения строительства» (есть → E).

## Интерфейс

- Наведи курсор на здание или клетку — справа внизу панель: название, содержимое, энергия; для пустой клетки — тип пола / руды.
- Меню строительства справа внизу: категории (турели, буры, транспорт, жидкости, энергия, стены, производство, юниты). Чтобы увидеть название и цену блока — кликни по иконке (подсказка появляется над меню).
- Ресурсы ядра — сверху по центру. В дереве технологий слева — «Общие предметы» (сумма по всем секторам).
- Кнопки внизу справа: задачи, база данных, дерево технологий, карта планеты.

## Дерево технологий

- Серые узлы — можно изучать, красные с замком — условия не выполнены (наведи — покажет, что нужно).
- ВНИМАНИЕ: клик по узлу СРАЗУ вкладывает в него все доступные ресурсы, без подтверждения. Чтобы просто посмотреть цену — наводи курсор, не кликай.
- В подсказке ресурсы показаны как «есть / нужно».

## Механики (выводы)

- Ядро «Осколок» вмещает 4 тыс. каждого ресурса; сверх лимита ядро сжигает входящее. Полное ядро = добыча впустую → направь сырьё в заводы.
- Заводы выгружают продукт в соседние блоки, в т.ч. прямо в ядро.
- Узкие места раннего Серпуло: кремний (плавильня: уголь + 2 песка + энергия) и метастекло (печь: свинец + песок + энергия). Печи часто голодают — проверь, сколько сырья у них внутри (наведи курсор).
- Высадка в новый сектор: N → выбрать сектор → «Высадка» → «Максимум» → «Высадка». Берутся ресурсы из сектора-источника (до 2000 каждого).
- В новом секторе сразу пауза (Пробел) → M (откуда враги) → оборона → добыча.

## Блоки (горячие клавиши из подсказок)

- Производство: графитовый пресс [7,1], кремниевая плавильня [7,3], печь [7,5], мешалка пиротита [7,0], плавильня [7,1,2], измельчитель [7,1,6], мусоросжигатель [7,1,8].
- Турели: рассеиватель (против авиации, медь 85 + свинец 45) [1,2], обжигатель (огнемёт, медь 25 + графит 22) [1,3].
